# Maelström — Jauges, choix et dialogues

Ce document définit le rôle des deux jauges et la manière de les employer dans les futures scènes. Il décrit à la fois le système actuellement implanté et les règles de design à conserver.

## 1. Principe directeur

Les deux jauges ne mesurent pas la même chose.

- **La Conscience cosmique détermine ce que Laurence peut remarquer, comprendre ou rapprocher.**
- **La Lucidité détermine s’il peut distinguer le fait observé de l’interprétation qu’on lui propose.**

Un personnage très informé peut être manipulable. Un personnage très lucide peut manquer d’informations. La situation la plus puissante est celle où Laurence comprend beaucoup tout en gardant assez de recul pour contester Nyarlathotep.

| État | Expérience de jeu |
| --- | --- |
| Lucidité haute, Conscience basse | Laurence résiste bien, mais ne voit pas encore le tableau d’ensemble. |
| Lucidité haute, Conscience haute | Laurence découvre les liens et peut refuser les conclusions imposées. |
| Lucidité basse, Conscience basse | Laurence subit surtout la peur, la confusion et les interruptions. |
| Lucidité basse, Conscience haute | Laurence perçoit beaucoup de choses, mais devient vulnérable aux interprétations de Nyarlathotep. |

Les jauges modifient le chemin, les formulations et les conséquences locales. **Elles ne choisissent jamais automatiquement la fin.**

## 2. Lucidité

### Définition

La Lucidité représente la distance critique de Laurence : reconnaître la différence entre un souvenir, une observation, une hypothèse et une suggestion extérieure.

Elle est comprise entre 0 et 100 :

- **31–100 : stable** ;
- **1–30 : avertissement** ;
- **0 : crise**.

La crise n’est ni une mort ni un écran d’échec. Le jeu continue avec une conséquence précise et identifiable.

### Quand la faire baisser

Une perte de Lucidité doit correspondre à une atteinte vécue, et non à une simple mauvaise réponse du joueur.

| Événement | Valeur indicative |
| --- | ---: |
| Malaise, contradiction personnelle, vision brève | −5 |
| Révélation qui attaque l’identité ou le souvenir | −10 |
| Accepter volontairement une vision invasive | −15 |
| Contact cosmique majeur, annoncé et mis en scène | −20 maximum |

Une association incorrecte dans le mini-jeu de connexions ne retire rien. Le joueur doit pouvoir défaire le lien, relire les fragments et essayer à nouveau.

Éviter les pertes arbitraires provoquées par l’examen d’un décor ordinaire. La perte doit être compréhensible après coup et, pour les montants importants, annoncée par le son, l’image ou le dialogue.

### Que produit une crise

À 0, choisir une conséquence adaptée à la scène :

- Laurence ne peut plus formuler une objection complexe ;
- une option permettant de contester Nyarlathotep disparaît temporairement ;
- Laurence accepte une suggestion, mais le journal l’étiquette comme **suggestion**, jamais comme fait ;
- l’exploration est interrompue et Laurence doit sortir du lieu ;
- un témoin écourte l’entretien en voyant son état ;
- Laurence confond momentanément deux éléments, puis peut les réexaminer après un ancrage.

Une crise ne doit jamais :

- tuer automatiquement Laurence ;
- effacer des fragments déjà obtenus ;
- transformer une suggestion en vérité objective ;
- rendre la partie impossible à terminer.

### Les ancrages

Les ancrages restaurent la Lucidité parce qu’ils redonnent à Laurence un contact avec le personnel, l’humain ou le vérifiable.

Exemples :

- vérifier une date, une signature ou un objet matériel ;
- parler sincèrement avec un personnage de confiance ;
- retrouver un souvenir personnel non contaminé par une interprétation cosmique ;
- accomplir un geste familier ;
- comparer deux sources indépendantes.

Chaque ancrage ne fonctionne qu’une fois par étape. Les gains indicatifs sont :

- petit geste d’attention : +5 ;
- véritable vérification ou échange humain : +10 ;
- résolution personnelle majeure : +15, rarement.

La prière ou la contemplation de la Vierge peuvent être des ancrages pour Laurence sans prouver quoi que ce soit sur la cosmologie. Le bénéfice vient de son rapport intime au geste, pas d’un pouvoir visible de la statue.

### Alcool et tabac

- **Alcool** : atténue temporairement les manifestations d’une crise. Il ne restaure aucune Lucidité et ne permet pas de formuler une objection qui exige une Lucidité supérieure à zéro.
- **Tabac** : crée une pause et révèle clairement au joueur l’état de Laurence. Il ne restaure aucune jauge.

Dans une future scène, l’alcool peut réduire les déformations visuelles ou permettre de poursuivre une action simple, mais il ne doit jamais devenir un soin.

## 3. Conscience cosmique

### Définition

La Conscience cosmique mesure les connaissances accumulées sur les phénomènes qui dépassent le monde humain. Elle est comprise entre 0 et 100 et ne peut que progresser.

Elle ne représente ni la folie, ni la corruption, ni une opinion. Elle ne garantit jamais que l’interprétation de Laurence est juste.

### Comment la faire progresser

Elle augmente lors d’une acquisition réelle :

- connexion valide entre deux fragments : +5 ;
- hypothèse importante confirmée par une source indépendante : +5 à +10 ;
- compréhension d’un mécanisme cosmique : +10 ;
- révélation majeure, comme l’échange des corps : +10 à +15.

Le simple fait de ramasser un document ne doit pas toujours augmenter la jauge. Le document fournit d’abord un fragment ; la compréhension naît souvent de sa connexion avec un autre élément.

### Ce qu’elle débloque

Selon la scène, elle peut :

- ajouter une observation facultative sur une image fixe ;
- rendre visible un fragment déjà présent dans le décor ;
- proposer une question plus précise à un témoin ;
- permettre une nouvelle connexion dans le journal ;
- reconnaître qu’une formulation de Nyarlathotep ressemble à une suggestion antérieure ;
- distinguer une technologie yithienne d’un objet religieux ;
- modifier la narration intérieure de Laurence.

Ce qu’elle ne doit pas faire :

- révéler gratuitement un indice que le joueur n’a pas trouvé ;
- afficher directement « la bonne réponse » ;
- remplacer une preuve matérielle ;
- imposer une fin en fonction d’un seuil.

## 4. Structure d’un dialogue important

Un dialogue d’enquête ou un rêve doit idéalement séparer quatre niveaux.

1. **Le fait** : ce qui a été vu, entendu ou lu.
2. **La connexion** : le rapport raisonnable entre plusieurs faits.
3. **L’interprétation** : ce que Laurence, un témoin ou Nyarlathotep prétend que cela signifie.
4. **L’attitude** : savoir, résister ou demander que cela cesse.

Exemple :

- Fait A : le père demande le nom de Laurence sur le quai.
- Fait B : Bell situe son changement autour de 1921.
- Connexion : son comportement a changé autour de 1921.
- Interprétation de Nyarlathotep : pour comprendre, Laurence doit subir la même chose.
- Attitude du joueur : réclamer une vision, demander du repos ou refuser la conclusion.

La connexion reste acquise même si Laurence refuse l’interprétation.

## 5. Concevoir les choix

Les choix les plus intéressants ne sont pas « bonne réponse / mauvaise réponse ». Ils expriment une méthode et produisent une conséquence lisible.

### Attitudes persistantes

- **Foi** : Laurence conserve ou recherche un cadre religieux.
- **Esprit critique** : Laurence questionne l’autorité, l’apparence et l’interprétation proposée.
- **Connaissance** : « Je veux savoir. »
- **Repos** : « Je veux que cela cesse. »
- **Résistance** : « Je chercherai, mais je refuse que tu décides du sens. »

Ces attitudes sont dérivées des choix principaux enregistrés et sauvegardés. Les questions de dialogue que le joueur peut toutes épuiser ne doivent pas compter comme des décisions principales.

Deux tendances peuvent préparer du contenu futur :

- **Foi + recherche de vérité → tendance Azathoth** ;
- **Esprit critique + désir que tout cesse → tendance Cthulhu**.

Une tendance peut choisir un rêve, une formulation ou une tentation particulière. Elle ne doit pas sélectionner automatiquement la fin. Si les deux tendances sont à égalité, le parcours reste indéterminé jusqu’à un nouveau choix significatif.

### Règles pratiques

- Une option de savoir peut donner accès à davantage de contenu, avec un risque clairement annoncé.
- Une option de repos peut préserver Laurence ou interrompre la scène sans punir le joueur par une impasse.
- Une option de résistance ne doit pas fermer l’enquête ; elle refuse l’interprétation, pas les faits.
- Une option spéciale liée à la Conscience cosmique doit révéler une lecture nouvelle, pas être automatiquement correcte.
- Une option indisponible à cause d’une crise peut être absente ou visible mais désactivée, avec une explication claire.

## 6. Modèle pour une future scène

Chaque scène importante peut être conçue avec cette fiche :

| Élément | Question de conception |
| --- | --- |
| Fait observable | Que peut constater Laurence sans interprétation ? |
| Fragment | Quelle information stable rejoint le journal ? |
| Condition | Faut-il un objet, une conversation ou un niveau de Conscience ? |
| Choc | Pourquoi la Lucidité baisserait-elle ici ? |
| Ancrage | Quel geste humain ou quelle vérification peut la restaurer ? |
| Connexion | Avec quel autre fragment cette information devient-elle utile ? |
| Manipulation | Quelle conclusion trop rapide Nyarlathotep peut-il proposer ? |
| Conséquence de crise | Que se passe-t-il à 0 sans arrêter le jeu ? |
| Attitude | Comment le choix exprime-t-il connaissance, repos ou résistance ? |

### Exemple : visite à l’asile

- Laurence consulte une fiche médicale : aucun délire religieux n’est noté avant 1921.
- Il compare une écriture antérieure et une écriture postérieure : fragment matériel.
- Une réponse précise du père rappelle un détail historique, mais pas un souvenir familial.
- La connexion renforce l’hypothèse d’une discontinuité de personne.
- Nyarlathotep suggère que le père a sacrifié son identité pour accéder au savoir.
- Avec de la Lucidité, Laurence peut répondre que rien ne prouve un sacrifice volontaire.
- En crise, il doit interrompre la visite ou laisse momentanément cette suggestion entrer dans son journal.
- Un échange avec un infirmier, une photographie familiale ou la vérification d’une date sert d’ancrage unique.

## 7. Utilisation dans le code actuel

Modifier directement une jauge :

```ts
store.modifyStat('lucidity', -10);
store.modifyStat('consciousness', 5);
```

Utiliser un ancrage une seule fois pour une étape :

```ts
store.useAnchor('act2_asylum', 'family_photograph', 10);
```

Un choix visible dans un dialogue peut enregistrer automatiquement ses conséquences :

```ts
{
    id: 'asylum_request_forbidden_record',
    text: i18n.t('act2_asylum.requestForbiddenRecord'),
    consequences: {
        lucidityDelta: -5,
        attitudeTag: 'knowledge',
    },
}
```

L’interface de dialogue appelle déjà `recordChoice`. Il ne faut pas appliquer une seconde fois les mêmes conséquences dans `onComplete`.

Pour une condition :

```ts
const store = useGameStore.getState();

if (store.consciousness >= 20 && store.hasFragment('asylum_handwriting_change')) {
    // Ajouter une observation ou une question spéciale.
}

if (store.lucidity > 0) {
    // Autoriser la contestation d’une interprétation imposée.
}
```

Lire la tendance narrative mémorisée :

```ts
const tendency = store.getNarrativeTendency();

if (tendency === 'azathoth') {
    // Préparer un rêve orienté vers la foi et la recherche de vérité.
} else if (tendency === 'cthulhu') {
    // Préparer un rêve orienté vers le doute et le désir que tout cesse.
}
```

Les seuils de Conscience doivent rester rares et justifiés. Préférer une condition composée — connaissance et fragment réellement découvert — à un simple nombre.

## 8. Checklist avant d’ajouter une scène

- Les faits sont-ils séparés des interprétations ?
- La Conscience cosmique ouvre-t-elle une possibilité sans donner gratuitement la vérité ?
- La perte de Lucidité correspond-elle à un choc identifiable ?
- La scène possède-t-elle au moins un ancrage logique si elle inflige plusieurs pertes ?
- L’ancrage est-il limité à une utilisation par étape ?
- La crise a-t-elle une conséquence jouable autre qu’un game over ?
- Nyarlathotep utilise-t-il les découvertes de Laurence sans inventer les indices manqués ?
- Le choix exprime-t-il une attitude plutôt qu’une réponse moralement correcte ?
- La fin de la scène reste-t-elle accessible quelle que soit la valeur des jauges ?
